# MC Admin Panel 2 и MC Mod Collector

Два нативных приложения для Windows (Tauri 2 + Rust) с общей библиотекой:

- **MC Admin Panel** — создание и администрирование серверов Minecraft.
- **MC Mod Collector** — подбор модов в сборку: поиск на Modrinth и CurseForge, моды с любых сайтов, проверка совместимости, установка в свой Minecraft и экспорт в `.mrpack`. Готовую сборку панель ставит и на сервер, и на клиент.

Вместо Chromium используется системный WebView2 (есть в Windows 10/11; установщик докачает его при отсутствии).

## Установка
Скачайте со страницы [релизов](https://github.com/TRUMEN228/mc-admin-panel/releases):

| Файл | Что это |
|---|---|
| `MCAdminPanel-X.Y.Z-Setup.exe` | Панель, установщик. Данные — `%APPDATA%\MC Admin Panel`, серверы и бэкапы — `Документы\MC Servers`. Обновляется автоматически. |
| `MCAdminPanel-X.Y.Z-Portable.exe` | Панель без установки: всё хранится в `MC Admin Panel Data` рядом с exe. |
| `MCModCollector-X.Y.Z-Setup.exe` | Сборщик модов, установщик. Сборки — `%APPDATA%\MC Mod Collector`. Обновляется автоматически. |
| `MCModCollector-X.Y.Z-Portable.exe` | Сборщик без установки: данные в `MC Mod Collector Data` рядом с exe. |

Портативный режим включается словом «Portable» в имени файла.

## MC Admin Panel
- **Создание сервера**: Vanilla, Paper, Fabric, Forge, NeoForge, любая версия Minecraft, включая снапшоты. Панель сама скачивает нужную Java (Adoptium), запускает установщики и принимает EULA.
- **Мониторинг**: CPU, RAM, игроки и аптайм с графиками; загрузка системы видна в боковой панели.
- **Консоль**: подсветка строк, фильтр, автодополнение команд (Tab), история (↑↓), быстрые команды и свои кнопки. Кириллица корректна в обе стороны.
- **Бэкапы**: zip с ротацией слотов, автобэкап по таймеру. Бэкап работающего сервера безопасен: save-off → save-all → архив → save-on.
- **Моды и плагины**: каталоги Modrinth, CurseForge (нужен бесплатный API-ключ), Hangar и SpigotMC с установкой зависимостей. Превью модов, карточки проектов со скриншотами, проверка и установка обновлений модов. Перетаскивание .jar в окно.
- **Сборки .mrpack** (с Modrinth или из MC Mod Collector): новый сервер из сборки, установка сборки на существующий сервер (только серверные моды), набор модов для клиента из сборки.
- **Файлы**: просмотр папки сервера и встроенный редактор конфигов (перед сохранением делается .bak).
- **Диагностика сбоев**: вероятная причина падения (память, порт, Java, зависимости и конфликты модов, аргументы JVM) и crash-report.
- **Подключение**: локальный и внешний адрес, открытие порта в брандмауэре Windows, проверка доступности из интернета.
- **Смена версии** Minecraft или загрузчика с автоматическим бэкапом; наборы флагов JVM (Aikar, ZGC).
- **Наборы модов клиента**: из модов сервера, из папки или из сборки; применение к `.minecraft` и профиль Fabric в лаунчере.
- **Настройки мира**, **игроки** (OP, белый список, баны), **трей**, **автозапуск с Windows**, **уведомления**, **палитра команд** `Ctrl+K`, **веб-доступ** (по умолчанию выключен), **прокси**.

## MC Mod Collector
- **Сборки**: название, версия Minecraft, загрузчик (Fabric, Forge, NeoForge, Quilt), версия сборки и автор.
- **Каталоги**: Modrinth и CurseForge с превью и скриншотами; при добавлении мода подбирается версия под сборку, обязательные зависимости добавляются сами.
- **Моды с других сайтов**: .jar-файлы (перетаскиванием или через выбор файлов), прямые ссылки, целая папка `mods`. Файлы опознаются в каталогах по хешу, неизвестные хранятся внутри сборки.
- **Клиент / сервер**: для каждого мода видно и можно переключить, на какую сторону он ставится.
- **Проверка**: обновления модов и смена версии Minecraft с подбором совместимых версий (несовместимые отмечаются).
- **В мой Minecraft**: замена папки `mods` (прежняя сохраняется как `mods_backup_*`) и профиль загрузчика в лаунчере.
- **Экспорт .mrpack** — файл открывается в MC Admin Panel, Prism Launcher, Modrinth App и других лаунчерах.

## Разработка
Нужны Rust (MSVC), Node.js и WebView2.
```
npm install
npm run dev                  # панель
npm run collector            # сборщик модов
npm run release              # релиз панели в release/panel/
npm run release:collector    # релиз сборщика в release/collector/
cargo test --workspace --lib # модульные тесты
```
- `src-tauri/` — ядро панели, `ui/` — её интерфейс.
- `collector/src-tauri/` — ядро сборщика, `collector/ui/` — его интерфейс.
- `crates/mccore/` — общая библиотека: каталоги модов, превью, версии, `.mrpack`, HTTP с прокси.
- `MCPANEL_DATA=<папка>` / `MCCOLLECTOR_DATA=<папка>` — запуск с отдельной папкой данных (для тестов).
- Отладочная сборка сборщика открывает интерфейс и в браузере: http://127.0.0.1:7791.

### Выпуск версии
1. Поднимите версию: панели — в `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, `package.json`; сборщика — в `collector/src-tauri/tauri.conf.json` и `collector/src-tauri/Cargo.toml`.
2. Создайте и запушьте тег: `v2.2.0` для панели или `collector-v1.0.0` для сборщика.
3. GitHub Actions соберёт установщик, портативный exe и `latest.json` и опубликует релиз. Релизы сборщика не помечаются «последними», а его файл обновлений лежит в постоянном релизе `collector-latest` — так обновления двух приложений не пересекаются.

Обновления подписываются ключом (секрет `TAURI_SIGNING_PRIVATE_KEY`). Локальная копия ключа — `~/.tauri/mc-admin-panel.key`; без него выпустить обновление для уже установленных приложений невозможно.
