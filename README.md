# MC Admin Panel 2

Нативное приложение для Windows (Tauri 2 + Rust), чтобы создавать и администрировать серверы Minecraft.
Вместо Chromium используется системный WebView2. Встроенного веб-сервера нет: интерфейс общается с ядром на Rust напрямую через IPC.

## Установка
Команда `npm run release` собирает в папку `release/` два файла:
- **`MC Admin Panel 2.0.0 Setup.exe`** — установщик. Данные панели хранятся в `%APPDATA%\MC Admin Panel` (данные прежней Electron-версии подхватываются автоматически), серверы и бэкапы по умолчанию — в `Документы\MC Servers`.
- **`MC Admin Panel 2.0.0 Portable.exe`** — портативная версия без установки. Всё (настройки, Java, серверы, бэкапы) хранится в папке `MC Admin Panel Data` рядом с exe, так что панель можно переносить на флешке. Режим включается словом «Portable» в имени файла.

Обеим версиям нужен WebView2, он уже есть в Windows 10/11. Установщик при отсутствии WebView2 докачает его сам.

## Возможности
- **Создание сервера**: Vanilla, Paper, Fabric, Forge, NeoForge, любая версия Minecraft, включая снапшоты. Панель сама скачивает нужную Java (Adoptium), запускает установщики и принимает EULA.
- **Мониторинг**: CPU, RAM, игроки и аптайм с графиками; загрузка системы видна в боковой панели.
- **Консоль**: подсветка строк, фильтр, автодополнение команд (Tab), история (↑↓), быстрые команды и свои кнопки. Кириллица корректна в обе стороны.
- **Бэкапы**: zip с ротацией слотов, автобэкап по таймеру. Бэкап работающего сервера безопасен: save-off → save-all → архив → save-on.
- **Моды и плагины**: каталог Modrinth с зависимостями, перетаскивание .jar в окно, включение и выключение модов.
- **Наборы модов клиента**: можно собрать набор из модов сервера, применить к `.minecraft` и создать профиль Fabric в лаунчере.
- **Настройки мира**: редактор `server.properties` с группами и подсказками. Порядок строк и комментарии в файле сохраняются.
- **Игроки**: онлайн, OP, белый список, баны.
- **Нативное для Windows**: фон Mica в Windows 11, светлая и тёмная темы, трей с управлением серверами, автозапуск с Windows, системные уведомления (сбой сервера, установка, ошибки бэкапа), прогресс задач на панели задач, системные диалоги.
- **Палитра команд** `Ctrl+K`: переход к серверам и разделам, запуск, остановка, бэкап. `Ctrl+B` сворачивает боковую панель.
- **Веб-доступ** (по умолчанию выключен): та же панель в браузере, включается в настройках. Доступ из локальной сети — только с паролем.
- **Прокси**: системный прокси Windows подхватывается автоматически, его получают и Java, и установщики.

## Разработка
Нужны Rust (MSVC), Node.js и WebView2.
```
npm install
npm run dev        # запуск приложения
npm run build      # релизная сборка и установщик NSIS
npm run release    # установщик + портативный exe в release/
```
- `ui/` — интерфейс (HTML/CSS/JS без сборщика).
- `src-tauri/src/` — ядро: `servers.rs` (процессы, мониторинг), `installer.rs` (версии, Java, установка), `backups.rs`, `mods.rs` (Modrinth, наборы), `importer.rs`, `native.rs` (трей, окно, уведомления), `web.rs` (веб-доступ), `api.rs` (команды UI).
- `MCPANEL_DATA=<папка>` — запуск с отдельной папкой данных (для тестов).
